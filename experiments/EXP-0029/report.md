## 边界

- 调用图只能找“主流程不可达且会输出”的函数；如果后门不可达但也不输出，
  或其他可达函数才是真正的利用点，这套启发式会漏。
- 可达性以 entry / main / 输入读取函数为根；根识别失败（极端的 stripped 布局）会退化。
- 候选仍需执行验证；本实验用偏移探测真跑确认，产品内只标注“需执行”。
