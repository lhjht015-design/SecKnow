topic: 黑盒行为刻画能把一部分"题目特有逻辑"变成可反解的结构——但边界必须说清楚
hypothesis: 出题人给的加密脚本/校验器可以只执行、不读源码，用探测判定结构类别后自动反解。
experiment:
  - 8 个自写但故意"实现古怪"的挑战脚本（`experiments/EXP-0017/chal/`），
    求解器通过 `tools/blackbox_worker.src` 只做执行探测，从不读取源码。
  - 判定顺序：确定性 → 长度保持 → 依赖矩阵（逐字节翻 0xFF）→
      逐字节：先试 a*x+b，再逐位置建 256 项表；
      置换：探测定位置映射；
      其余：测 GF(2) 列向量 + 6 组线性性抽检 → 高斯消元反解；
      校验器：按前缀长度逐字节爬坡。
  - 每个解都用"重新加密后等于原密文"复核；判不出结构就拒绝。
  - 结果（连续 2 次一致）：
      P1 逐字节 S 盒         → bytewise_table    6278 次探测，40 ms
      P2 逐字节仿射 a*x+b    → bytewise_affine    124 次，1.6 ms
      P3 GF(2) 随机可逆矩阵   → gf2_linear         220 次，12.8 ms
      P4 三轮 Feistel        → gf2_linear         239 次，6.4 ms
      P5 前缀校验器          → prefix_oracle      375 次，120 ms
      N1 sha256              → not_length_preserving 拒绝
      N2 非线性 32 位混合     → structure_unknown 拒绝
      N3 每次换随机掩码       → nondeterministic 拒绝
    正样本 5/5，负样本 3/3 如实拒绝，总计 7484 次探测、平均 22.9 ms/题。
result:
  - **五个关键点**：
    1. **"读懂逻辑"可以换成"刻画行为"。** 出题人怎么实现不重要，
       重要的是这个函数在输入输出上属于什么结构。依赖矩阵先区分
       逐字节 / 置换 / 稠密；再按结构选反解方法。
    2. **差分探测是最便宜的结构信号。** 只翻一个字节、看哪些输出字节变化，
       n 次探测就能把"位置独立 / 置换 / 全混合"分开；比读代码快得多。
    3. **GF(2) 线性检测能拆穿"看起来非线性"的实现。** P4 的 Feistel
       有三轮循环移位与异或，直觉上像强混淆；但轮函数是线性的，
       整个映射仍是仿射的，8n+1 次探测就能测出矩阵并消元反解。
    4. **校验器只需要一个前缀信号。** P5 没有可逆脚本，只有"对了多少字节"，
       逐字节枚举可打印字符即可，375 次探测拿到完整 flag。
    5. **拒绝路径和求解路径同样重要。** N1/N2/N3 分别是不可逆、非线性、
       非确定性；系统在 0.1–2 ms 内返回明确原因，不编造明文。
  - **适用边界（必须写进交付说明）**：
    - 需要能**执行**题目给的脚本/二进制（CTF 常见：给 enc.py 或校验器）；
      只给一段密文、没有 oracle 时，本方法不成立。
    - 结构覆盖仅限：确定、长度保持、逐字节双射 / 位置置换 / GF(2) 仿射。
      任意非线性状态机、带真实密码学轮函数的构造，仍需要读代码或符号执行。
    - 校验器必须**泄露进度**（前缀长度、逐字节对错、或可测的时序差）。
      只回 "wrong" 的校验器不在覆盖范围内。
    - 运行主办方代码本身有风险，真实使用应放进沙箱。
conclusion:
  - LAW-0017 说"六成步骤是题目特有逻辑，检索变不出来"——这是对的，
    但其中一部分并没有"不可解"，只是**不可检索**。把这类题目从
    "召回一个单元"改成"对 oracle 做结构判定"，就能在没有 LLM、
    没有题库条目的情况下给出**可执行且可复核**的反解。
  - 这条路的代价极低（毫秒级、几千次调用），而且天然可验证：
    解出来的明文重新加密必须等于原密文，不成立就拒绝。
  - 它不能消灭"逻辑新颖性"：真正的非线性构造仍然需要符号执行或人工阅读。
    下一步应该补符号执行（angr）与黑盒二进制校验器，把覆盖从脚本扩到 ELF。
next: 把四种策略接入契约单元库（oracle → strategy → plain）；
      angr 符号执行处理非线性分支；时序侧信道版前缀爬坡；沙箱化执行。
