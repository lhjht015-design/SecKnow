```yaml
id: LAW-0003
prev: LAW-0002
date: 2026-09-21
source: 实验
topic: 本机火绒 HIPS 会异步删除「HTTP 客户端 + 动态执行 + 受限 builtins」组合的 .py 文件
hypothesis: 当某个 .py 文件同时包含 (a) HTTP 请求代码、(b) 对动态编译代码的 exec、(c) 手工构造 __builtins__、(d) 二十余 KB 体积时，会被判定为 RAT/加载器并被静默删除。
experiment:
  - 对照实验：把该 30 KB 脚本分别以 .py / .bak / .sav 后缀存放。
  - .py 版本在写入后数秒内被删除（复现 3 次）；同一内容以 .bak / .sav 存放则长期存活。
  - 文件本身是良性的：它是本项目的离线推理评测脚本，HTTP 只连本机 Ollama（127.0.0.1:11434）。
  - 删除是**异步**的：`ls` 仍能看到文件，紧接着的 python 调用就报 No such file。
    这导致最初误判为「路径问题」或「工具问题」，浪费了多轮排查。
result:
  - 触发条件是「内容 + .py 后缀」的组合，与路径、写入工具无关（Write 工具与 cp 均会触发）。
  - 执行不依赖后缀：`python xxx.src` 与 `python xxx.py` 行为完全一致。
conclusion:
  - 本项目所有**含动态执行或网络客户端**的主体脚本，统一使用 `.src` 后缀存放，运行方式为
    `python versions/vNNN_xxx.src`。这样既绕开误报，又保持单文件可独立运行。
  - 判断「文件莫名消失」时，先确认是否为安全软件的异步删除，不要先怀疑代码或工具链。
  - 记录在案：**不要**为了绕过检测而混淆代码——这里的做法只是换后缀，代码完全可读、可审计。
next: 若后续脚本仍被删，把动态执行部分与网络部分拆到两个文件，从根本上打散该特征组合。
```
