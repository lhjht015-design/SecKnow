```yaml

prev: LAW-0020
date: 2026-11-11
source: 实验
topic: ret2win 在 stripped / -O2 / 改名后仍可定位，但必须靠字符串引用 + 执行验证
hypothesis: v014 的 ret2win 单元只依赖符号表；真实题常见 -O2、-s、函数改名，
            补一条"字符串引用"路线后仍能找到后门。
experiment:
  - 同一份 `vuln.c` 编五个变体（EXP-0015）：
      vuln_o0          O0 带符号（回归）
      vuln_o2          O2 带符号
      vuln_o2s         O2 -s（符号表被剥离）
      vuln_renamed_o2  后门改名为 helper_a3f9（符号在，但名字不再像后门）
      vuln_nowin_o2s   无后门、无 flag 字样
      vuln_decoy_o2s   有引用 flag 字样的函数，但输出假 flag
  - 新增单元 `find_win_candidates`：两条路线
      符号启发式：名字含 win / backdoor / getshell / flag
      字符串引用：`lea reg, [rip+X]` 指向 "/tmp/flag.txt"、"flag{" 等字符串，
                  再把该指令所在的函数入口当作候选
  - 每个候选 × {加对齐 ret, 不加} 都真实执行；只有 stdout 出现**期望的** flag 才算成功。
  - 结果（连续 3 次稳定）：
      R0 O0 带符号        → ✓ 740 ms   symbol:win
      R1 O2 带符号        → ✓ 740 ms   symbol:win
      R2 O2 stripped      → ✓ 730 ms   string_ref:/tmp/flag.txt
      R3 O2 改名          → ✓ 740 ms   string_ref:/tmp/flag.txt
      N1 无后门           → ✓ 如实拒绝（win_not_found，3 ms）
      N2 假后门           → ✓ 如实拒绝（execute_failed，880 ms）
result:
  - **三个关键点**：
    1. **符号剥离和改名是同一类问题。** 两者都让"按名字找函数"失效；
       但后门总要引用 flag 文件或 flag 字样，**字符串引用改不掉**。
       R2 与 R3 都只能走这条路，且都找到了正确入口。
    2. **函数入口检测有一个 -O2 陷阱。** 我原本的写法是"往回扫，先遇到
       endbr64 或 push rbp 就停"，但 -O2 的函数常常是
       `endbr64; push r12; push rbp; ...`——先撞到 `push rbp`，
       于是把入口报成函数中间，跳过去必崩。正确做法是**先在整段里找
       16 字节对齐的 endbr64**，找不到才退回 push rbp。
       （这个 bug 在首轮就被 R1 暴露：符号路径能解，字符串路径却打不中。）
    3. **候选必须靠执行验证，不能看到 flag{...} 就收工。** N2 的 decoy
       真的打印了 `flag{decoy_not_the_answer}`；如果只做正则匹配，
       会把它当成成功。判据必须是"输出等于期望 flag"，否则继续试下一个候选，
       全部失败则返回 `execute_failed`。
  - 反面同样重要：N1 没有任何候选时返回 `win_not_found`，
    3 ms 内结束，而不是随便挑一个函数硬跳。
conclusion:
  - ret2win 的可迁移性不依赖符号表，而依赖**后门的行为痕迹**：
    它要读 flag 文件、要打印 flag 字样。把这条痕迹变成候选生成规则，
    符号剥离与改名就不再是障碍。
  - "候选生成"与"候选验证"必须分开：前者可以宽松（宁多勿漏），
    后者必须是真实执行且比对期望值（宁严勿滥）。
  - 与 LAW-0018 一脉相承：所有静态推断都要被真实执行证伪。
next: canary + PIE + ret2libc 的组合；把 ret2win 的字符串引用候选接入通用规划器；
      stripped 且完全无 flag 字样的真实题（需要靠调用图/系统调用模式识别）。
```
